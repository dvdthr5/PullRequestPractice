# Pull Request Practice

This is a simple activity I created to use with students in the UCSC CMPM118: Collaborative Research Experience in Engineering course that I teach. There is a simple student_readme.md file that provides instructions for the student. The instructor will need to do a little bit of setup. I created an issue for each of my students, for them to get familiar with using issues, as well. 

# Areas of Practice
Students can use this to practice version control, branching, opening and writing pull requests, and reviewing and handling merge conflicts.
